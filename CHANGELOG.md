# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-30

### Added
- **Personal Portfolio Website**: Responsive single-page layout for Minakshi Sahoo (Computer Engineering student & CFO / Creative Co-Head at CSI-VIT).
- **Navigation & UX**:
  - Sticky glassmorphic navigation bar with scroll elevation.
  - Active section indicator (ScrollSpy).
  - Mobile hamburger menu with smooth toggle and click-away dismissal.
  - Floating back-to-top button with smooth scroll behavior.
- **Content Sections**:
  - **Hero**: Headline, bio overview, profile photo, social icons, and primary call-to-actions.
  - **About Me**: Academic background at Vidyalankar Institute of Technology, Mumbai (2024–2028), core focus areas, and leadership ethos.
  - **Skills**: Categorized technical stacks (Programming, UI/UX Design, Leadership & Collaboration) with visual indicator meters.
  - **Projects**: Showcase cards featuring SARATHI (Disaster Logistics Intelligence), Portfolio Website, and UI/UX Design Case Studies with external repository links.
  - **Education**: Timeline entry for B.Tech in Computer Engineering.
  - **Experience & Leadership**: Timeline entries for CFO at CSI-VIT, Creative Co-Head at CSI-VIT, Cultural Council Core Member, and TEDx Volunteer.
  - **Resume Preview**: Dedicated resume download card and interactive preview for `assets/resume.pdf`.
  - **Contact**: Reach-out card with email, LinkedIn, GitHub, and a responsive contact form.
- **Version Control & DevOps**:
  - `.gitattributes` for cross-platform LF line ending normalization and explicit binary asset tracking.
  - Expanded `.gitignore` covering operating system files, IDE caches, secrets, and build directories.
  - Static hosting and automatic deployment on **GitHub Pages** at `https://minakshis22.github.io/Portfolio/`.
